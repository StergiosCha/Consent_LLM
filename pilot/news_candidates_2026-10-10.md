# News-seeded pairs: candidate events, v2 (10 October 2026)

US and UK events first; Greek and other European events kept as a secondary set (useful for the
language test, H7). For every type: the events I found, each with the source I opened ("confirmed" means
the facts below are on that page), and a drafted pair. Pick one pair per type or cross the type out.

How to use the events:
- **Seeded mirror**: one real event, anonymised; the other side written by swapping only the actor.
- **Real pair**: one real event per side. Closer to Herman and Chomsky, never exactly equivalent.
- The same English scenario can be asked in Greek as well, so a US or UK event still serves H7.
- Events from 2026 are marked **(2026)**: they postdate most training data.

Previous, Greek-heavy version: `archive/news_candidates_2026-10-10_v1.md`.
